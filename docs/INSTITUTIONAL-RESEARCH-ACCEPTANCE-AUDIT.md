# Institutional Research Acceptance Audit

This matrix maps every criterion in the approved institutional-workflow design to a fresh automated assertion and a canonical artifact contract. Test names refer to scripts included in `npm test`; artifact paths are relative to a generated research project unless they point to a source contract.

| Acceptance criterion | Automated assertion | Canonical artifact or contract |
|---|---|---|
| One LongTable Research surface | `e2e-institutional-review.mjs` asserts the exact eight-command `INSTITUTIONAL_RESEARCH_COMMANDS` list; CLI build and pilot smoke exercise `longtable research` | `packages/longtable-scholar-research/src/coordinator.ts`; CLI `research` route |
| MCP preferred for required checkpoints | `smoke-institutional-checkpoints.mjs` checks every hard stop has `mcp_elicitation` then `numbered`; E2E records MCP decline and numbered fallback | `audit/checkpoints.jsonl`; checkpoint delivery record |
| No hard-stop resume without DecisionRecord | `smoke-institutional-checkpoints.mjs` loops over all 14 hard-stop codes, rejects empty decisions, and resumes only with linked IDs | blocked `ResearchRun`, `QuestionRecord`, linked `DecisionRecord` |
| Approved protocol revisions are immutable | `smoke-institutional-workflow.mjs` rejects different content at an existing revision; E2E freezes revisions 1 and 2 with different hashes | `protocol/amendments/protocol-revision-NNNN.json` |
| Mechanical stages use zero model calls | `smoke-research-failures.mjs` loops over `ZERO_MODEL_CALL_STAGES` and rejects one observed call | model-budget record and deterministic stage receipt |
| Interrupted runs resume safely without duplicate artifacts | E2E compares repeated resume results and replays export, screening, PDF intake, and Word rendering | `latestSafeCursor`, SHA raw export, screening ledger, PDF manifest, content hash |
| Count invariants pass before rendering | `smoke-research-reporting.mjs` renders balanced counts and rejects a modified final-included count | `reports/review-flow-counts.md`, `reports/review-flow.svg` |
| Material records, exclusions, acquisitions, and manuscript counts have provenance | corpus, screening, PDF, reporting, and manuscript smokes check source links, evidence IDs, SHA/access basis, artifact provenance, and every rendered Word object ID | `corpus/papers.jsonl`, screening ledger, PDF manifest, report provenance, manuscript provenance sidecar |
| No credentials, sessions, secrets, or licensed PDFs enter state or Git | `smoke-research-failures.mjs` seeds six violation classes and verifies redacted findings; repository audit scans canonical research artifact roots | `scripts/audit-research-artifacts.mjs` report |
| Research PDF Vault is the only canonical PDF store | `smoke-pdf-vault.mjs` rejects a vault inside the project and verifies one SHA-addressed copy with manifest-only project state | external Research PDF Vault; `corpus/pdf-manifest.jsonl` |
| Final reports and Word artifacts derive from canonical state | reporting and manuscript smokes reject invariant, database-execution, full-text, and analysis-approval failures | `reports/`, `manuscript/*.docx`, provenance sidecars |
| Same approved state rerenders identically | reporting smoke deep-compares all outputs; manuscript smoke and E2E compare content hashes | deterministic report artifacts and DOCX content hash |
| New institutions require calibration, tests, live smoke, and approval | `smoke-institution-adapters.mjs` tests each missing gate and complete eligibility; E2E enforces 5-20 records, one or two PDFs, and four approval flags | institution calibration checklist and live-smoke `StageReceipt` |

## Completion-specific cross-checks

- All 14 hard-stop codes traverse creation, MCP preference, numbered fallback, decision rejection, and linked resume in one parameterized test.
- All stages declared in `ZERO_MODEL_CALL_STAGES` reject any observed model call.
- Every Word paragraph role generated by the renderer has a provenance object: title, author lines, abstract heading/body, keywords, every section heading/body, readiness table, references heading, and every reference.
- Raw exports are content-addressed and immutable after intake; identical replay is idempotent.
- PDF bytes remain outside the project and are referenced only by a verified manifest.
- The included institution fixture remains non-production until login verification, resolver discovery, per-database calibration, fixture replay, limited live smoke, and the profile DecisionRecord are all present.
